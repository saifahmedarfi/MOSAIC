# CLAUDE.md

Phase 0 — the pre-registered falsification.

**To run Phase 0 — or any part of it — follow [RUN_PHASE0.md](RUN_PHASE0.md) exactly.** It is
the execution contract: stage order, exact commands, hard gates and stop conditions.
[GUIDE.md](GUIDE.md) explains what the code does and which proposal section each part satisfies;
[README.md](README.md) is the overview.

Non-negotiables, repeated here because they are easy to violate before reading the runbook:

- **Edit only `src/phase0_source.py`.** The `.ipynb`, `src/phase0_lib.py`, `environment.yml`,
  `scripts/*` and `.gitignore` are generated by `python src/build_notebook.py`. Edits to them
  are overwritten.
- **`preregistration.json` is frozen and must be committed before any sweep run exists.** Never
  edit, regenerate or work around it. A `REFUSED` verdict from a hash mismatch is the mechanism
  working.
- **Never adjust a criterion, α, feature list, oracle set, seed set or budget to change the
  verdict.** Stop and ask instead.
- **The verdict binds.** `PIVOT` means stop and write up the null. Phases 1–3 are gated on `GO`.
- **Report only numbers that appear in command output.** If a stage failed or was skipped, say
  so with the output.
